# documentation-audit

> Systematically verify documentation claims against codebase reality using two-pass extraction and pattern expansion. Runs in an isolated forked context.

- **Version:** 2.0.1
- **Source:** https://github.com/2389-research/documentation-audit

## Install

Default — any agent (Claude Code, Cursor, Codex, …) via [vercel-labs/skills](https://github.com/vercel-labs/skills):

```
npx skills add 2389-research/documentation-audit
```

Or natively in Claude Code:

```
/plugin marketplace add 2389-research/claude-plugins
/plugin install documentation-audit@2389-research
```
